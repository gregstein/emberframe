# Bütün cümleler
> Kuralları Yaz penceresinin tanıdığı her cümle, tek sayfada. `…` yerine bir ad, bir sayı ya da bir işlem yazılır.
:: 📖 Başvuru sayfası

!note Nasıl okunur
Olaylar kenardan başlar ve iki noktayla biter. Eylemler içeriden (dört boşluk) yazılır. Aynı cümleler Kurallar ve Sayılar penceresindeki listelerde de vardır.

## Metnin bölümleri

| Yazım | Anlamı |
| `Sayılar:` | Altına, içeriden, sayılar yazılır: `Puan = 0` |
| `… komutu:` | Bir komut tanımlar. |
| `… komutu, …, … ile:` | Değer alan bir komut tanımlar. |

## Olaylar

| Cümle | Ne zaman olur |
| `Film başlayınca:` | Film açılınca, bir kez. |
| `Bir sahne başlayınca:` | Her sahneye girişte. |
| `… tuşuna basılınca:` | Tuşa basıldığı anda. |
| `… tuşu bırakılınca:` | Tuş bırakıldığı anda. |
| `… nesnesine tıklanınca:` | Nesneye fareyle tıklanınca. |
| `… nesnesi … nesnesine değince:` | İki nesne birbirine değmeye başlayınca. |
| `… nesnesi sahnenin … değince:` | Nesne sahnenin bir kenarına ulaşınca. |
| `Her … saniyede bir:` | Durmadan, o aralıkla. |
| `… saniye sonra:` | Film başladıktan o kadar sonra, bir kez. |
| `… sayısı … olunca:` | Sayı tam o değere gelince. |
| `… sayısı … değerini geçince:` | Sayı o değerin üstüne çıkınca. |
| `… sayısı … değerinin altına inince:` | Sayı o değerin altına düşünce. |

Tuşlar: Boşluk, Yukarı Ok, Aşağı Ok, Sol Ok, Sağ Ok, Enter, A–Z harfleri ve 0–9 rakamları.

Kenarlar: `alt kenarına`, `üst kenarına`, `sol kenarına`, `sağ kenarına`, `bir kenarına`.

Olaya koşul eklemek: olayın sonuna, iki noktadan önce, virgülle:

| Koşul | Anlamı |
| `…, … sayısı … ise:` | Sayı o değere eşitse |
| `…, … sayısı … değerinden büyükse:` | Sayı o değerden büyükse |
| `…, … sayısı … değerinden küçükse:` | Sayı o değerden küçükse |

## Eylemler: nesneyi göster, taşı, değiştir

| Cümle | Ne yapar |
| `… nesnesini göster` | Gizli nesneyi gösterir. |
| `… nesnesini gizle` | Nesneyi gizler. |
| `… nesnesini bir an yanıp söndür` | Kısa süre yanıp söner. |
| `… nesnesini … sağa, … aşağı taşı` | Olduğu yerden o kadar kaydırır (eksi sayı: sola, yukarı). |
| `… nesnesini …, … konumuna koy` | Verilen x, y yerine koyar. |
| `… nesnesini rastgele bir yere koy` | Sahnede şansa bağlı bir yere. |
| `… nesnesini üstte rastgele bir yere koy` | Sahnenin üstünde şansa bağlı bir yere. |
| `… nesnesini … derece döndür` | O kadar derece çevirir. |
| `… nesnesi saniyede … tur dönsün` | Sürekli döndürür (eksi: ters yön; 0: durdur). |
| `… nesnesini yüzde … boyuta getir` | Çizildiği boyun yüzdesi. |
| `… nesnesini yüzde … opak yap` | 0 görünmez, 100 çizildiği gibi. |

## Eylemler: hareket ettir

| Cümle | Ne yapar |
| `… nesnesini … yükseğe zıplat` | Zıplatır (Düş ve Zıpla gerekir). |
| `… nesnesi … … hızla gitsin` | Yöne doğru hızlanarak gider: `Araba nesnesi sağa 300 hızla gitsin` |
| `… nesnesi yavaşlayarak dursun` | Giden nesne yavaşlayıp durur. |
| `… nesnesi dursun` | Giden nesne hemen durur. |
| `… nesnesi … nesnesini … hızla izlesin` | Öteki nesnenin peşine takılır (0: bırakır). |
| `… nesnesini yüzde … hızlandır` | Her şeyini o oranda hızlandırır. |
| `… nesnesini yüzde … yavaşlat` | Her şeyini o oranda yavaşlatır. |

Yönler: `sağa`, `sola`, `yukarı`, `aşağı`.

## Eylemler: kopyala, bağla, davranış ver

| Cümle | Ne yapar |
| `… nesnesinin kopyasını … nesnesinin yerinde oluştur` | Birincinin kopyasını ikincinin olduğu yerde çıkarır. |
| `… nesnesini sil` | Kopyayı yok eder. |
| `… nesnesini … nesnesine bağla` | Birinci, ikinci nereye giderse oraya gider. |
| `… nesnesini serbest bırak` | Bağı çözer. |
| `… nesnesine … davranışını ver` | Davranışlar menüsündeki bir davranışı verir. |
| `… nesnesinden … davranışını al` | Davranışı kaldırır. |
| `kamera … nesnesini izlesin` | Kamerayı o nesneye verir. |
| `kamera yerinde dursun` | Kamera kaymayı bırakır. |

## Eylemler: sayılar

| Cümle | Ne yapar |
| `… sayısını … artır` | Sayıya ekler. |
| `… sayısını … azalt` | Sayıdan çıkarır. |
| `… sayısını … yap` | Sayıyı o değere getirir. |
| `… sayısını … ile … arasında rastgele yap` | Şansa bağlı bir değer verir. |

İşlemlerde kullanılabilenler: `+ - * /`, parantez, sayı adları, `rastgele(a, b)`, `Ad.x`, `Ad.y`.

## Eylemler: film, sahne, ses

| Cümle | Ne yapar |
| `filmi durdur` | Zaman çizelgesi durur. |
| `filmi oynat` | Zaman çizelgesi devam eder. |
| `…. kareye git ve oynat` | O kareye gider, oynar. |
| `…. kareye git ve dur` | O kareye gider, durur. |
| `sonraki sahneye git` | Sıradaki sahneye geçer. |
| `…. sahneye git` | Numarası verilen sahneye geçer. |
| `… sesini çal` | Sesi çalar. |
| `her şeyi durdur` | Filmi olduğu gibi dondurur. |
| `baştan başla` | İlk sahneye döner, sayıları sıfırlar. |

## Bloklar: içine eylem yazılanlar

| Cümle | Ne yapar |
| `eğer …:` | Koşul tutarsa içindekileri yapar. |
| `değilse:` | `eğer` tutmazsa içindekileri yapar. |
| `… kez yinele:` | İçindekileri o kadar kez yapar. |
| `… yinele:` | Koşul tuttukça yapar: `Puan sayısı 0 değerinden büyükse yinele:` |
| `… saniye bekle` | Devam etmeden önce bekler. |
| `… komutunu yap` | Bir komutu çağırır. |
| `… komutunu …, … ile yap` | Bir komutu değerlerle çağırır. |

## Yazım kuralları

- Adında boşluk olan nesne tırnak içine alınır: `"Kırmızı Top" nesnesini gizle`
- Ondalık sayı nokta ya da virgülle yazılır: `0.5` ya da `0,5`
- Cümlenin ilk harfi büyük ya da küçük olabilir.
- Boş satırlar serbesttir.
- Arayüz İngilizceyken aynı cümlelerin İngilizceleri yazılır.
