# PisiWorks ve PisiAnimasyon 0.2.0

0.1.0'dan sonraki küçük bir sürüm: **Hakkında** kutusu yenilendi. Programların geri kalanı 0.1.0 ile aynıdır; onun notları: [0.1.0](0.1.0.md).

## Kurulum

`pisiworks_0.2.0_amd64.deb` dosyasını indirin ve indirdiğiniz klasörde:

```bash
sudo apt install ./pisiworks_0.2.0_amd64.deb
```

0.1.0 kuruluysa üstüne kurulur. Pardus 25'te denenmiştir.

## Değişenler

- **Yardım > Hakkında**, iki programda da aynı bilgileri gösterir: iki programın ortak sitesi ve kitabı (<https://muratsapmaz.github.io/PisiAnimasyon/>), geliştiricinin sitesi (<https://muratsapmaz.web.app/>), kaynak kodun deposu ve Emberframe'in yazarı Med Amine Belbachir'e teşekkür.
- Kutudaki üç düğme (**Site ve kitap**, **Geliştiricinin sitesi**, **Kaynak kod (GitHub)**) bu adresleri tarayıcıda açar; adres yazmak gerekmez.
- Kutuya sığmayıp iki ucundan kesilen satırlar kısaltıldı.
